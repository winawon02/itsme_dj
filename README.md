# 잇츠미 대전 웹 자산 배포

이 폴더는 공개 홈페이지용 자산만 담는 Git 업로드 준비본입니다.
로컬에서 `node scripts/prepare-git-assets.mjs`로 생성합니다.

- `assets/`: 원본 사이트에서 확보한 공개 이미지·폰트·영상
- `style.css`, `script.js`: 아임웹 본문에 공통 적용할 파일
- `asset-manifest.json`: 원본과의 SHA-256 대응 및 대용량 제외 목록

아직 GitHub에 업로드하거나 공개하지 않았습니다. 배포 주소는 확정되지 않았습니다.
개별 파일이 100MiB 이상이면 일반 Git 업로드 대상으로 복사하지 않고 manifest의
`oversized`에 기록합니다. 원본 파일은 `imweb/assets/`에 그대로 남습니다.
해당 영상의 별도 배포 경로가 정해지기 전에는 전체 자산 배포가 완료된 것이 아닙니다.

아임웹에서는 로컬 상대경로가 아닌 배포 후 확인한 HTTPS 주소를 사용합니다.
CSS/JS를 직접 복사할 때도 `copy.html`에서 그 주소로 변환합니다.
이 폴더에 계정·DB·환경설정·로그 파일을 추가하지 마세요.
